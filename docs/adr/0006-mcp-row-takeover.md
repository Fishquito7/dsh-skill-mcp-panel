# 面板接管每一条 mcp-client 行，并提供原文编辑

Issue #67。维护者 Fishquito7 与提出者 jiangzhenguo 一致：不要只给块外行加一个开关。

## 背景

面板原先把 `@deepseek-ai/dsh-mcp-client` 分成两类：受管块内且 `id` 以 `panel-mcp-` 开头的行可以启停、编辑、删除；其余（手写、从别的 profile 迁来、或 id 不是这个前缀）在 MCP 页标成「外部管理」/「受管块外」，卡片上没有任何操作。现实里多数配置恰恰是手写的。

只给外部行加 `disabled` 开关能解决「临时关掉省上下文」，但编辑、删除、OAuth 仍然要去改文件，而且「先收编进受管块才能编辑」会整段重写、破坏手写字节。

## 决策

1. **全接管**。文件里每一条 `name: @deepseek-ai/dsh-mcp-client` 的行都能启停、用表单编辑、删除、做 OAuth。不再用受管块或 `panel-mcp-*` 区分能不能操作。
2. **就地改，不搬家**。已有行留在原地。启停只翻转这一条的 `disabled`（无键则在**这一条最后一个键**后面按同缩进插入，所以没有 `id` 的手写行也能开关；启用且独占一行则整行删除；`!!js` 拒绝代写）。删除只剪掉这一条的文本跨度——**跨度到内容最后一行为止**，条目后面的注释、空行和下一行的说明注释都不动；删掉受管块最后一行时 begin/end 标记成对收掉，块内注释保留、块外内容不卷入。表单保存和 OAuth 写 Authorization 也只重写这一条。文件其余字节不动，换行符跟随原文件（CRLF 不会被掺进 LF）。
3. **表单与原文并存**。表单继续管 transport / command / env / headers 等已建模字段，并保留表单不认识的键（例如 `maxInstructionBytes`）和手写 id；没有 id 的行保存后仍然没有 id（不补 `panel-mcp-*`），已有的 `disabled`（布尔 / `!!js` / 手写标量）原样保留。卡片上的「原文」（CLI：`dsh-panel mcp raw` / `--set`）把这一条的 YAML 按字节交还给用户，但**不许改位置**：缩进和所在列表必须和原来一致（受管块 `insert` 成员不能变成顶层条目，否则 append 会变成 override），提交的片段可以不带 id。
4. **不迁移**。旧受管块里的行本来就是普通 mcp-client 行，改完之后只是不再被特殊对待。新建的服务器仍追加进受管块，id 仍是 `panel-mcp-<serverName>`。
5. **非 MCP 行仍按 ADR-0003**。受管块里不属于 MCP 的条目不被折叠、不被改写；界面继续提示它们。

## Considered Options

- **只加外部行开关**（issue 原文的实现建议）：本地已验证热启停和字节往返，但编辑/删除仍断档，也保留了「受管 / 外部」两套卡片。维护者明确要求不要停在这一步。
- **收编进受管块再编辑**：整段重写会吃掉注释、键序和 `!!js`，与「手写和面板管理不再二选一」相反。
- **表单保存仍整块重写所有面板行**：会把没被这次编辑碰到的行也规范化。改为只替换目标 entry。

## Consequences

- `externalServers` 仍留在 wire schema 里，但列表现在始终是空数组；全部 MCP 行都在 `servers`。
- 手写 id 在表单保存后保持不变。只有 id 恰好是 `panel-mcp-<旧 serverName>` 时，改名才会把 id 换成新的 `panel-mcp-*`。
- 表单保存会重排**这一条**的键序（未知键留在 config 末尾）。要逐字节保留注释和键序，用原文编辑。启停本身不重排。已有的 `!!js` `disabled` 在表单和 OAuth 写回时保留表达式，不会被收成布尔值。面板也不把它当成已启用：卡片显示停用。保存和原文写回不再等 loader 把这条表达式收成某个布尔值，避免宿主求值结果不是 `true` 时热加载等待超时。
- `serverName` 一律先看非空的 `config.serverName`，没有时才用 `panel-mcp-*` 的 id 后缀。CLI 和网关用同一规则。
- **行身份是 `serverName` + `entryId` 两个键**。所有操作都先按「两个都对上」定位，缺一个才退回单键匹配：重复 `id`（不同名字）或重复 `serverName`（不同 id）都能唯一定位到用户点的那条卡片；两个都重复才报错。CLI 用 `--id <entryId>` 指定、`list --ids` 打印 entryId。文件里本来就有重名不会阻止保存（只拒绝**新增**重名），可以用原文逐条把重名改掉。
- 非布尔的 `disabled`（`"true"`、`1`…）按停用展示，但表单保存原样保留；`!!js` 的 `disabled` 在视图里标 `disabledExpr`，界面据此禁用开关并给出「用原文改」的说明，不再提供一个点了必然报错的开关，`toolCount` 也不再按 `enabled` 强制归零。
- 原文编辑的保真边界收紧了：只保证「这一条的内容 + 文件其余字节」，条目自己的注释/键序仍会在表单保存时被重排（原文编辑按提交内容写回）。重复 `id`/`serverName` 时，`raw --set` 可以一次改一条直到唯一。
- `dsh-panel mcp list` 不再打印「受管 / 外部」。
